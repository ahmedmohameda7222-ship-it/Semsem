# Free-tier Cloudflare TURN setup for Sasa ↔ Semsem

The app already supports Cloudflare Realtime TURN in `api/voice.js` using server-side, short-lived credentials. No domain purchase or WebRTC architecture rewrite is required.

## Free allowance and charges

Cloudflare Realtime currently includes a **shared 1,000 GB/month free allowance** for TURN and SFU egress. Additional usage costs **$0.05/GB**. It is a free usage allowance, **not an unconditional spending cap**. Review Cloudflare Billing before activation and configure notifications/limits where offered; never assume automatic zero-overage enforcement.

Official references:
- https://developers.cloudflare.com/realtime/turn/generate-credentials/
- https://developers.cloudflare.com/realtime/sfu/platform/pricing/
- https://developers.cloudflare.com/realtime/turn/faq/

## Configure securely

1. Sign into your own Cloudflare account at https://dash.cloudflare.com.
2. Open **Realtime / TURN** in the account dashboard. Create a TURN key named `Our Space`.
3. The key has a public **UID/Key ID** and a private, long-term **secret/key**. Save the secret in a password manager; it can be shown only once.
4. Open the existing Vercel project: https://vercel.com/ahmed-s-projectssasa/our-space/settings/environment-variables
5. Add these **Production** environment variables (server-only, Sensitive):
   - `CLOUDFLARE_TURN_KEY_ID` = the Cloudflare TURN key UID
   - `CLOUDFLARE_TURN_API_TOKEN` = the corresponding TURN key secret
6. **Redeploy Production** to activate them. Do **not** prefix these variables with `VITE_`.
7. The existing authenticated `POST /api/voice` action `{"action":"ice"}` should then return `relay: true` and a list containing `turn:` or `turns:` URLs with temporary credentials. **Never log or share the credentials in chat.**
8. With the two installed iPhone PWAs, confirm **two-way voice** on separate Egyptian/German Wi-Fi/cellular networks. Check caller ringback, incoming ringtone, and decline, end and minimize.

If the user hasn't created the Cloudflare key, the existing code returns STUN only (`relay: false`), which **cannot guarantee** calls across restrictive NATs. Do not mark remote relay as configured before the two variables exist and the authenticated ICE response confirms `relay: true`.

## Usage and secrets

- Credentials are generated by the Vercel API only for authenticated users, and the long-term TURN secret never reaches client JavaScript.
- Individual clients receive short-lived TURN credentials for WebRTC, which is expected; don't expose the administrative key.
- A failed TURN service should never be confused with a healthy relay; inspect the existing API error status.
- The first 1,000 GB allowance is shared across the Cloudflare account's Realtime TURN/SFU usage. The allowance can be exceeded; review billing policy.
